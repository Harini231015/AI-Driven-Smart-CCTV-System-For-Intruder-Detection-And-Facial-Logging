# AI-Driven-Smart-CCTV-System-For-Intruder-Detection-And-Facial-Logging
Project Overview

An AI and IoT-based smart surveillance system designed to automatically detect motion, capture images, recognize faces, and identify unknown persons. The system uses a Raspberry Pi 4, camera, PIR sensor, Arduino UNO, and GSM module to provide automated security alerts.

🚀 Features
Motion detection using PIR sensor
AI-based facial recognition
Automatic image capture and facial logging
SMS alerts using SIM900A GSM module
Alarm/light control using relay module
Live CCTV monitoring through a mobile application
Local storage of captured images
